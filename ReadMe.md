# First Portfolio

Este é o meu primeiro portfólio, um site pessoal para apresentar minhas habilidades, experiências e projetos como desenvolvedor(a). Construído com HTML e CSS.

## Estrutura

- `index.html`: Página inicial.
- `about.html`: Sobre mim.
- `curriculum.html`: Meu currículo.
- `repositories.html`: Meus projetos no GitHub.
- `assets/`: Imagens e recursos.
- `styles/`: Arquivos CSS.

## Tecnologias

- HTML5
- CSS3
